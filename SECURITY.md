# Security Policy

## Supported Versions

Only the latest stable commit on the `main` branch is supported with security patches.

## Reporting a Vulnerability

If you identify a security vulnerability in the AI-Expert-Roadmap project (such as a cross-site scripting flaw in site navigation components, insecure dependencies, or workflow/deployment credential leaks), please do **not** open a public issue.

Please report vulnerabilities privately by emailing the maintainers or using GitHub's private vulnerability reporting feature.
